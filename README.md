# FIAP - POO

Repositório com os projetos e desafios práticos da disciplina de
Programação Orientada a Objetos.

## Organização do repositório

O conteúdo é separado em pastas por dia de aula. Cada pasta contém o
projeto completo daquela aula, já evoluído em cima da aula anterior, com
seu próprio código-fonte e `README.md` explicando o que foi feito.

```
.
├── 130826/
│   └── content..
├── 190226/
│   └── content..
└── ...
```

- **Aula1/** — estrutura inicial da classe: atributos e construtor
  (o objeto ainda não tem comportamento).
- **Aula2/** — evolução da Aula1: adição de métodos que alteram o
  estado do objeto, com regras de negócio (validações).
- As próximas aulas seguem o mesmo padrão: uma pasta nova, evoluindo o
  projeto da pasta anterior.

Cada pasta é independente e pode ser aberta diretamente no IntelliJ
(ou outra IDE) como projeto Java. Para entender o que foi feito em
cada etapa, veja o `README.md` dentro da respectiva pasta.

## Como navegar

1. Entre na pasta da aula desejada (ex: `Aula2/`).
2. Leia o `README.md` local para entender o objetivo e o funcionamento
   daquela etapa.
3. Abra a pasta no IntelliJ para rodar o código.
